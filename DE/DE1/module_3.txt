What is a Data Source?
A data source is any system, application, device, or process that generates, stores, or provides data that can be extracted for analysis and business intelligence. Data sources are the origin points where data is created before it enters your data pipelines.

"The average enterprise works with over 400 different data sources!"

What are Transactional Systems?
Transactional systems (also called OLTP - Online Transaction Processing) are designed to manage and process real-time business transactions. They are optimized for:

High volume of concurrent users
Fast read/write operations
ACID compliance (Atomicity, Consistency, Isolation, Durability)
Data integrity and consistency

Real-World Example: Extracting Sales Data
# Example: Extracting Salesforce Opportunities via API
from simple_salesforce import Salesforce

# Connect to Salesforce
sf = Salesforce(
    username='user@company.com',
    password='password',
    security_token='token',
    domain='login'  # or 'test' for sandbox
)

# Query Opportunities
query = """
    SELECT Id, Name, Amount, StageName, CloseDate,
           Account.Name, Owner.Name
    FROM Opportunity
    WHERE CloseDate >= LAST_N_DAYS:90
    AND StageName != 'Closed Lost'
"""

results = sf.query_all(query)

# Process results
for record in results['records']:
    print(f"Opportunity: {record['Name']}")
    print(f"  Amount: ${record['Amount']}")
    print(f"  Stage: {record['StageName']}")
    print(f"  Account: {record['Account']['Name']}")

What is an API?
An API (Application Programming Interface) is a set of protocols and tools that allows different software applications to communicate with each other. For data engineers, APIs are crucial for:

Extracting data from SaaS applications
Integrating third-party data services
Building data pipelines without direct database access
Enabling real-time data synchronization

Handling Rate Limits
# Example: Exponential backoff with rate limit handling
import time
import requests

def api_call_with_retry(url, headers, max_retries=5):
    for attempt in range(max_retries):
        response = requests.get(url, headers=headers)
        
        if response.status_code == 200:
            return response.json()
        elif response.status_code == 429:  # Rate limited
            retry_after = int(response.headers.get('Retry-After', 60))
            print(f"Rate limited. Waiting {retry_after}s...")
            time.sleep(retry_after)
        else:
            wait_time = 2 ** attempt  # Exponential backoff
            time.sleep(wait_time)
    
    raise Exception("Max retries exceeded")

Python REST API Client Example
import requests
from typing import Generator, Dict

class RESTAPIClient:
    def __init__(self, base_url: str, api_key: str):
        self.base_url = base_url
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        }
    
    def get_all_records(self, endpoint: str) -> Generator[Dict, None, None]:
        """Paginate through all records from an endpoint."""
        page = 1
        while True:
            response = requests.get(
                f"{self.base_url}/{endpoint}",
                headers=self.headers,
                params={"page": page, "per_page": 100}
            )
            response.raise_for_status()
            data = response.json()
            
            for record in data["data"]:
                yield record
            
            if page >= data["pagination"]["total_pages"]:
                break
            page += 1

import requests
import pandas as pd

def extract_from_api(base_url, api_key, endpoint):
    all_data = []
    page = 1
    while True:
        response = requests.get(
            f"{base_url}/{endpoint}",
            headers={"Authorization": f"Bearer {api_key}"},
            params={"page": page, "per_page": 100}
        )
        data = response.json()
        if not data.get("results"):
            break
        all_data.extend(data["results"])
        page += 1
    return pd.DataFrame(all_data)
