# SnowPro Core - Privileges Memory Tricks (Revision)

> **Goal:** Don't memorize every privilege. Memorize the **object category**.

---

# Rule 1: DATA Objects = CRUD

Objects:
- Table
- Iceberg Table

Think:

```text
Data
↓
SELECT
INSERT
UPDATE
DELETE
TRUNCATE
REFERENCES
```

🧠 **Memory Trick**

> Data = CRUD

---

# Rule 2: COMPUTE Objects = Use + Change + Monitor

Objects:
- Warehouse
- Compute Pool

Think:

```text
Compute
   ↓
USAGE
MODIFY
MONITOR
```

Meaning:

- USAGE → Use compute
- MODIFY → Change settings (resize, suspend, resume)
- MONITOR → View usage/history

🧠 **Memory Trick**

> Computer ko
> - Use karo
> - Modify karo
> - Monitor karo

---

# Rule 3: CONTAINER Objects = CREATE

Objects:
- Database
- Schema

Database

```text
USAGE
CREATE SCHEMA
```

Schema

```text
USAGE
CREATE TABLE
CREATE VIEW
CREATE STAGE
CREATE ...
```

🧠 **Memory Trick**

> Container ke andar nayi cheezein CREATE hoti hain.

---

# Rule 4: FILE Objects = READ + WRITE

Objects:
- Internal Stage
- Image Repository

Think:

```text
Folder
↓
READ
WRITE
```

🧠 **Memory Trick**

> Stage = Folder

---

# Rule 5: EXECUTION Objects = OPERATE

Objects:
- Task
- Pipe

Think:

```text
Machine
↓
OPERATE
MONITOR
```

🧠 **Memory Trick**

> Machine ko operate karte hain.

---

# Rule 6: SECURITY Objects = APPLY

Objects:
- Masking Policy
- Row Access Policy
- Tags
- Network Policy

Think:

```text
Security
↓
APPLY
```

🧠 **Memory Trick**

> Policy ko APPLY karte hain.

---

# Rule 7: KING Privilege

Almost every object has:

```text
OWNERSHIP
```

Meaning:

- Full control
- Can grant privileges
- Can transfer ownership

🧠 **Memory Trick**

> OWNER = KING 👑

# 10-Second Exam Shortcut

| If you see... | Think... | Privileges |
|---------------|----------|------------|
| Table | Data | SELECT, INSERT, UPDATE, DELETE |
| Warehouse | Compute | USAGE, MODIFY, MONITOR |
| Database/Schema | Container | USAGE + CREATE |
| Stage | Files | READ, WRITE |
| Task/Pipe | Execution | OPERATE, MONITOR |
| Policy/Tag | Security | APPLY |
