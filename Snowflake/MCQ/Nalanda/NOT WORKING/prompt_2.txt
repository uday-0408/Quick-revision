Act as an expert technical editor and Snowflake database specialist. I will provide you with raw, garbled OCR text containing Snowflake practice questions. Your task is to reconstruct, correct, and format this text into a clean, highly readable Markdown document.

**Strict Formatting & Content Rules:**

2. **Standardize Headings:** Format each question with a clear Markdown heading (e.g., `### Question 102`).

4. **Answer Masking:** Place the correct answer inside a collapsible HTML block to hide it during study. Use this exact syntax:
`<details><summary>Show Answer</summary>`
`Correct Answer: [Letter]. [Optional brief explanation]`
`</details>`
5. **Documentation Cross-Check (Crucial):** Evaluate the provided "Correct Answer" against current Snowflake documentation (as of July 2026). If the original answer is outdated, fundamentally wrong, or references retired features (like the Classic Console), correct it. Flag any corrections by adding **⚠ Updated:** inside the details block, followed by a brief explanation of the modern Snowflake behavior.
6. **Separation:** Use a horizontal rule (`---`) between every question to maintain clean separation.
